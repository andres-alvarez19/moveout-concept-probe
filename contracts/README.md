# Contratos de pruebas de concepto

**Aún no existen contratos funcionales aprobados.** Se redactarán en la siguiente etapa a partir del SDD v0.5, SRS v2.3 y Contratos API v1.6.

Un contrato activo debe llamarse `POC-001.json`, `POC-002.json`, etc., y validar contra `factory/contract.schema.json` y las reglas semánticas de la CLI.

Copie `factory/templates/contract.template.json` para iniciar un contrato; ajuste identidad, trazabilidad, componentes, criterios y evidencias. No incluir credenciales, datos personales ni rutas a video corporal.

Cada contrato necesita aprobación humana antes de que el runner implemente código. Los contratos y los resultados de cada PoC deben revisarse mediante pull request.
